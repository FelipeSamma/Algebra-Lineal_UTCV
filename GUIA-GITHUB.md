# Cómo subir y mantener esta guía

[Volver al índice](README.md)

**Repositorio:** `FelipeSamma/Algebra-Lineal_UTCV`. El nombre de usuario de GitHub puede ser distinto del correo utilizado para iniciar sesión.

## Primera publicación

1. Extrae el ZIP y abre la carpeta `Algebra-Lineal`.
2. En GitHub, inicia la creación de un repositorio desde [github.com/new](https://github.com/new).
3. Comprueba el propietario y escribe `Algebra-Lineal_UTCV` como nombre.
4. Descripción sugerida: «Guía de aprendizaje de Álgebra Lineal con explicaciones sencillas y ejemplos paso a paso».
5. Elige público si necesitas que el profesor pueda abrir el enlace sin invitación; elige privado si quieres restringir el acceso y después dale acceso al profesor.
6. Crea el repositorio vacío, sin generar otro README.
7. Usa la opción de cargar archivos. Arrastra **el contenido** de la carpeta: `README.md`, `GUIA-GITHUB.md`, `temas` y `recursos`. No subas el ZIP como único archivo.
8. Guarda la carga con el mensaje «Agrega guía inicial de Álgebra Lineal».
9. Abre el README y entra en un tema para comprobar que los enlaces y las fórmulas se muestran correctamente.

## Cómo hacer cambios después

Abre un archivo `.md`, elige editar, modifica el texto y guarda el cambio con un mensaje breve que explique lo realizado. Un **commit** es un registro de esos cambios; no necesitas fingir etapas anteriores ni dividir artificialmente la primera entrega.

Ejemplos de mensajes para cambios reales:

- «Aclara mi explicación de la suma de vectores».
- «Agrega apuntes de la nueva clase».
- «Corrige un signo en el ejemplo de matrices».

Markdown es texto con marcas de formato: `#` crea un título, `##` un subtítulo y `[texto](ruta)` un enlace. Las fórmulas de esta guía están entre signos de dólar para que GitHub las muestre matemáticamente.

## Antes de entregar

- Revisa y adapta las conclusiones propuestas a lo que realmente comprendiste.
- Verifica que puedas explicar al menos un ejemplo de cada tema.
- Comparte el enlace de tu repositorio, no el de la referencia de tu compañero.
- Si es privado, comprueba que el profesor tenga acceso.
